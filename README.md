# S2Diff-MH

Clean research repository for hyperspectral image super-resolution / HSI-MSI fusion.

The repository currently contains:

1. **Innovation 1: sensor-degradation-consistent progressive diffusion**;
2. **registered Raw-MSI Direct fusion baseline**;
3. **Innovation 2 Stage-0: calibrated degradation-locked deformation identifiability test (CDRDI)**.

The abandoned GAAT-inspired V4 registration chain is intentionally not included.

## Innovation 1

Let `X` be the clean HR-HSI. A sensor degradation operator `D_t` produces the native observation at diffusion state `t`, and `U_t` lifts that observation back to the common HR computational grid:

```text
D~_t = U_t o D_t
x_t  = D~_t(X)
```

The predictor estimates the clean HR-HSI directly:

```text
X_hat_0 = F_theta(x_t, t, optional HR-MSI)
```

The deterministic reverse update is

```text
x_(t-1) = x_t + D~_(t-1)(X_hat_0) - D~_t(X_hat_0)
```

For the standard 4x experiment, `T=12` and the physical scales are:

```text
t=1..4   -> scale 1
t=5..8   -> scale 2
t=9..12  -> scale 4
```

Reverse inference therefore restores the observation along a 4 -> 2 -> 1 path.

## Degradation modes

- `physical`: shared Gaussian PSF parameterized by MTF at LR Nyquist + detector area integration/downsampling + normalized-adjoint lift;
- `gaussian_bicubic`: legacy Gaussian blur + bicubic downsampling baseline;
- `bicubic`: plain bicubic baseline.

The LR-HSI observation is generated by `ProgressiveDegradation.terminal_observation()`, not by the dataset loader. This keeps the dataset endpoint and diffusion endpoint strictly closed.

## Sensor protocol

Registered HR-MSI is synthesized by real sensor spectral-response integration:

- PaviaU -> IKONOS 4 bands;
- Chikusei -> WorldView-2 8 bands;
- Houston13 -> WorldView-2 8 bands.

Raw sensor response curves are stored under `data/srf/`, and HSI wavelength files are stored under `data/wavelengths/`.

## Models

- `v1`: compact time-conditioned clean-HSI predictor;
- `v2`: Innovation-1 spectral-spatial predictor;
- `raw_direct`: V2 HSI backbone + full Raw MSI feature encoder with direct three-scale injection.

`raw_direct` intentionally contains no MSI high-pass filter, no learned MSI transfer gate, no time-varying MSI injection schedule, and no registration module.

## Innovation 2 Stage-0: CDRDI geometry identifiability

Before coupling deformation to diffusion, the repository first tests one isolated question:

```text
fixed P0 + fixed R0 + no flow supervision -> can phi be recovered from observation closure?
```

The synthetic HSI observation is generated by forward acquisition:

```text
Y_M = R0(X)
Y_H = P0(W_phi(X))
```

With the shared spatial PSF, the fixed-degradation closure is

```text
R0(Y_H) ~= P0(W_phi(Y_M))
```

Only geometry is optimized. `P0` and `R0` are never learnable. The local deformation is generated from sparse control-point offsets and differentiable cubic B-spline interpolation. The solver uses a coarse rigid state followed by coarse and fine residual local fields. Ground-truth deformation is used only to synthesize the observation and compute EPE after solving; it is not passed to the solver.

Run a first sanity check with one synthetic deformation:

```bash
python validate_cdrdi_geometry.py \
  --dataset PaviaU \
  --device cuda \
  --cases 1 \
  --max_translation 4 \
  --max_rotation_deg 2 \
  --max_local_px 2 \
  --seed 10
```

Then use multiple random cases:

```bash
python validate_cdrdi_geometry.py \
  --dataset PaviaU \
  --device cuda \
  --cases 5 \
  --max_translation 4 \
  --max_rotation_deg 2 \
  --max_local_px 2 \
  --seed 10
```

The main diagnostic is total sampling-map EPE in HR pixels (`EPE_HR_mean` and `EPE_HR_p95`), not the separate rigid/local parameter error, because different rigid/local decompositions can describe nearly identical total acquisition geometry. `GT_commute_MAE` should remain close to numerical precision and verifies that the fixed shared `P0` and fixed `R0` paths close correctly.

This Stage-0 solver is direct differentiable optimization, not the final learned recursive deformation network. It exists only to establish whether the proposed deformation-only inverse problem is identifiable before adding another network or coupling it to Innovation 1.

## Train registered Raw-MSI Direct baseline

```bash
python main.py \
  --stage train \
  --dataset PaviaU \
  --degradation_mode physical \
  --diffusion_steps 12 \
  --predictor raw_direct \
  --base_channels 64 \
  --spectral_hidden 8 \
  --epochs 200 \
  --lambda_l1 1.0 \
  --lambda_sam 0.1 \
  --lambda_deg 0.0 \
  --seed 10
```

Without loading a model checkpoint:

```bash
python main.py \
  --stage diagnose \
  --dataset PaviaU \
  --degradation_mode physical \
  --predictor raw_direct
```

A standalone random-tensor closure check is also available:

```bash
python check_degradation_trajectory.py --mode physical --steps 12 --scale 4
```

## Reuse the old S2Diff Raw-Direct checkpoint

The old V3 Raw-Direct checkpoint contains obsolete gate parameters because all V3 ablations shared one state-dict structure. The clean model keeps the useful backbone/MSI encoder parameter names and filters the obsolete gate keys during loading.

Place the old checkpoint locally, then run:

```bash
python main.py \
  --stage train \
  --dataset PaviaU \
  --degradation_mode physical \
  --predictor raw_direct \
  --legacy_raw_direct_checkpoint ./checkpoints/legacy/PaviaU_innovation1_physical_v3_raw_direct.pth \
  --epochs 200 \
  --seed 10
```

The compatibility loader reports ignored, missing, and unexpected keys. For a matching old Raw-Direct checkpoint, only obsolete V3 gate keys should be ignored; meaningful Raw-Direct backbone/MSI keys should load.

- `models/predictor_v4_*`;
- `train_v4_*`;
- `diagnose_alignment_v4_*`;
- `tests/test_v4_*`;
- GAAT-inspired global rigid / local progressive / confidence / subpixel alignment;
